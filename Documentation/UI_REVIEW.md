# 界面梳理记录

本轮沿用奶油白、墨绿与插画图鉴的视觉风格，主要修复宽窄屏的信息拥挤、文字换行和学习反馈可见性。

## 已调整

| 页面 | 调整 |
| --- | --- |
| 今日 | 宽屏学习卡片采用连续背景与宽幅柔和过渡；最窄屏问候语与学习标题按语义排版；辅助功能字号下每日一词、本周进度改为纵向布局。 |
| 图鉴 / 收藏 | 三栏模式使用紧凑标题；按可用内容宽度安排词卡；大字号减少列数，辅助功能字号完整显示文字。 |
| 词条详情 | 窄窗口使用纵向首屏；收藏按钮移入状态行，给长单词留出完整宽度；音标空间不足时独立成行。 |
| 学习 | 答题后将反馈滚动到可见区域，下一题回到顶部；已答选项保持清晰对比度；宽屏页头、正文和底部按钮对齐。 |
| 我的 | 数字与单位可换行；大字号下今日指标纵排；空图表提示依据所选统计周期；隐藏 Mac 统计选择器的重复标签。 |
| 学习设置 | 同步检查增加进行中反馈与重复点击保护；缓存统计加载时显示“正在计算”；版本号独立显示。 |
| 主题 / 首次设置 | 辅助功能字号下主题改为单列并限制图片高度；学习目标与口音在窄窗口纵排，大字号使用菜单选择器。 |
| 共用组件 | 大字号下区块标题与操作上下排列；保留操作宽度，空状态说明允许完整换行。 |

## 验证

- macOS / iOS Simulator 最终版本均构建成功；严格 Swift 格式检查与 `git diff --check` 通过。
- 独立 iPhone Duo QA 模拟器上的既有 UI 流程通过：搜索、收藏与取消、主题切换、初见、答题反馈、继续及保存退出。
- 原生 macOS 页面渲染检查覆盖 320、350、560、600、640、760、900、1000、1120 pt 宽度及浅色 / 深色页面；这些窄宽度渲染用于布局检查，不等同于相应 iOS 设备截图。
- iOS 实际答题截图确认反馈完整显示在底部“继续”按钮上方，已答选项保持可读。
- 最终版本在独立 Duo 主显示面检查了辅助功能大字号 + 深色首页：标题、计划和开始按钮完整显示。

页面预览见 `Screenshots/ui-refinements.png`；实际 iOS 学习反馈见 `Screenshots/study-feedback-refined.png`。本轮未修改学习调度、词库和持久化模型。
